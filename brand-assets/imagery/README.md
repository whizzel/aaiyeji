# Aaiyeji imagery

## Current status

**No external photography is used anywhere in this project.** Every visual — hero
preview, invitation demos, gallery artwork, patterns and logos — is original
CSS/SVG artwork created for Aaiyeji. There are no hotlinked images, no stock
photos and no placeholder boxes.

The demo gallery artworks live in `public/images/demos/` (original SVG line art:
arches, marigolds, paisleys, petals, rings, coastlines). They are illustrative
placeholders for the real couple photography a live invitation would carry.

## Adding real photography later

1. Only use photography you own or that is properly licensed for commercial use
   (e.g. a client's own photos with permission, or a licensed stock source).
2. Download and store files locally under `public/images/` — never hotlink.
3. Optimise before committing (WebP/AVIF, sensible dimensions, `next/image`).
4. Record every file in the table below, including licence and attribution text
   if the licence requires it.
5. Never place real client personal data in demo content without consent.
