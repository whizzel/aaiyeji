# Aaiyeji brand assets

This folder is the **source of truth** for the Aaiyeji brand system. Everything
here is an **initial concept** created for the first release — the company can
replace any asset after formal brand approval without touching app code, as long
as file names and token names stay the same.

## Contents

| Path | What it is | Usage |
| ---- | ---------- | ----- |
| `brand-tokens.css` | Colour tokens as CSS custom properties | Imported by `app/globals.css`. Never hardcode brand colours in components. |
| `design-tokens.json` | The same tokens (plus type/spacing/motif notes) as JSON | Design reference, future tooling. Keep in sync with the CSS. |
| `brand-guidelines.md` | Palette, typography, logo rules, motifs, buttons, cards, tone of voice | Read before designing anything new. |
| `logo/aaiyeji-wordmark.svg` | Editable wordmark (symbol + AAIYEJI text) | Master artwork. The site header renders an HTML equivalent for crispness. |
| `logo/aaiyeji-symbol.svg` | Standalone arch + lotus monogram | Compact placements, watermarks, demo footers. |
| `logo/aaiyeji-favicon.svg` | Favicon mark on wine | Copied to `app/icon.svg` (Next.js serves it automatically). |
| `patterns/welcome-arch.svg` | Decorative ogee-arch line art | Hero decoration, demo welcome gates. Tint via `currentColor` in app usage. |
| `patterns/floral-divider.svg` | Lotus-bud divider with curling stems | Section dividers, invitation headers. |
| `social/og-cover.svg` | 1200×630 social cover master | The live PNG is generated by `app/opengraph-image.tsx` (social crawlers prefer raster). |
| `imagery/README.md` | Imagery policy + image register | All current artwork is original SVG; rules for adding licensed photography later. |

## Runtime copies

Next.js can only serve files from `public/`. Optimised runtime copies live in
`public/brand-assets/` and `app/icon.svg`.

- **Master (edit here):** `brand-assets/`
- **Runtime copy (served):** `public/brand-assets/`

After editing a master asset, copy it across:

```powershell
Copy-Item brand-assets/logo/*.svg, brand-assets/patterns/*.svg, brand-assets/social/*.svg public/brand-assets/ -Force
Copy-Item brand-assets/logo/aaiyeji-favicon.svg app/icon.svg -Force
```

## Updating the brand system

1. Change colours in `brand-tokens.css` **and** `design-tokens.json` together.
2. Replace logo SVGs in `logo/`, keeping the same file names.
3. Re-sync runtime copies (commands above).
4. Update `brand-guidelines.md` if rules changed.
5. Run `npm run build` to verify nothing broke.

## Status

All assets are **temporary but intentional originals** — no existing brand's
logo, artwork or copy is reused. The wordmark spells **AAIYEJI**. Final
approval, custom lettering and a registered logo are future work.
